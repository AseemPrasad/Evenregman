## Key Insights You'll Learn

### Critical
1. **Atomicity ≠ Consistency** - Transactions don't guarantee business rules
2. **CDC ≠ Real-time** - Eventually consistent system has tradeoffs everywhere
3. **Error handling ≠ Resilience** - Catching errors doesn't make system resilient

### High
4. **Concurrency is hard** - Requires careful thinking about ordering
5. **Testing is subtle** - Coverage doesn't equal quality
6. **Deployments are risky** - Schema changes can break production

### Medium
7. **Indexes matter** - Wrong index kills performance
8. **Data modeling compounds** - Early choices multiply in cost
9. **Monitoring is misleading** - Averages hide worst cases

### Low
10. **APIs need versioning** - Managing change is ongoing work
11. **Observability is critical** - Can't optimize what you can't measure
12. **Resilience is designed, not bolted-on** - Build in from the start
